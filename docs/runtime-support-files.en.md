# Runtime Support Files

> On-demand reference for graph-derived files plus the non-page runtime files `index.md` and `log/`.

## Graph Files

| File | Content | Generated by |
|------|---------|-------------|
| `edges.jsonl` | semantic relationships: paper-paper, paper-concept, claim/experiment/idea/provenance edges | `python3 tools/research_wiki.py add-edge` |
| `citations.jsonl` | bibliographic paper citations (`type: cites`) | `python3 tools/research_wiki.py add-citation` |
| `context_brief.md` | compressed context: claims + gaps + failed ideas + papers + edges (≤8000 chars) | `python3 tools/research_wiki.py rebuild-context-brief` |
| `open_questions.md` | open questions: under-supported claims + open questions from papers/topics | `python3 tools/research_wiki.py rebuild-open-questions` |

Semantic edge format: `{"from": "node_id", "to": "node_id", "type": "edge_type", "evidence": "...", "confidence": "high|medium|low", "date": "..."}`

Citation format: `{"from": "papers/citing", "to": "papers/cited", "type": "cites", "source": "literature_api|parsed_bib|manual", "date": "..."}`

## log/ Format

```markdown
# log

## ingest
[2026-04-07] added papers/lora-low-rank-adaptation | updated: concepts/parameter-efficient-fine-tuning

## lint
[2026-04-07] report: 0 red, 2 yellow, 1 blue

## check
[2026-04-08] report: 0 critical, 2 warnings, 1 suggestion
```

Weekly log files live at `wiki/log/{yyyy-mm-wN}.md`; `wN` is the week-of-month bucket, so days 1-7 are `w1`, days 8-14 are `w2`, and so on. Append entries with `tools/research_wiki.py log`, not by editing the files directly.
