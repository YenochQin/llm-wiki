# /paper-draft

> Draft a complete LaTeX paper from the PAPER_PLAN.md generated by /paper-plan.
> Write section by section: each section draws material from wiki claims/experiments/papers/concepts,
> generates LaTeX + figures + tables. BibTeX is fetched from DBLP/CrossRef (following citation-verification).
> Apply de-AI polish after completion (following academic-writing).
> Optional per-section agent-local review. Output a LaTeX manuscript in an independent external workspace.

## Inputs

- `plan`: path to PAPER_PLAN.md (e.g. `wiki/outputs/paper-plan-sparse-lora-2026-04-08.md`)
- `--paper-id` (optional): stable research-topic directory name without a date (e.g. `rmcdhf-radial-research`)
- `--draft-id` (optional): manuscript version named `YYYY-MM-DD-<purpose>` (e.g. `2026-10-06-rmcdhf-research`); selection and omission behavior are defined in Step 1
- `--review` (optional): enable per-section agent-local review
- `--sections` (optional): write only the specified section numbers from the selected PAPER_PLAN (e.g. `--sections 3,4`); used for incremental writing

## Outputs

- `<paper_root>/<paper-id>/<draft-id>/` directory outside the code repository (`PAPER_DIR`):
  - `PAPER_DIR/main.tex` — master file (includes each section)
  - `PAPER_DIR/sections/<section-id>.tex` — the actual selected PAPER_PLAN sections; theory, computation, observations, or other argument-specific sections as applicable
  - `PAPER_DIR/figures/` — generated figures (PDF/PNG)
  - `PAPER_DIR/tables/` — standalone table files (optional)
  - `PAPER_DIR/math_commands.tex` — shared math symbol definitions
  - `PAPER_DIR/references.bib` — verified BibTeX entries
- `wiki/log/` — appended log entry

## Workflow

**Pre-condition**: a configured llm-wiki repo (see `/setup`). Run Python tools through `uv run python -X utf8`, matching `README.md`. Resolve `@configured` and `@paper-root` before writing; resolve `@raw-root` only when reading raw inputs. `wiki/` below denotes the external configured wiki root:

Run commands from the repository root.

```shell
uv run python -X utf8 tools/research_wiki.py stats '@configured' --json
```

### Step 1: Initialize Paper Directory

Read [references/workspace-initialization.md](references/workspace-initialization.md) before selecting, creating, migrating, or forking a manuscript workspace. It defines omission behavior for `--paper-id`/`--draft-id`, version selection, venue templates, and the new-manuscript skeleton.

Resolve external roots first. Preserve the selected source filename and edit routine revisions in place; requested structural alternatives use a sibling version while preserving their parent. Missing/invalid `paper_root` blocks writes; never fall back to the repository.

### Step 2: Generate Figures and Tables

For entries actually needed by the selected sections, read [references/figures-and-tables.md](references/figures-and-tables.md). Generate figures/tables only from recorded source data and save them in `PAPER_DIR`; missing results remain placeholders/gaps, never fabricated measurements.

### Step 3: Write Sections

Read [references/section-writing.md](references/section-writing.md) for each section being drafted: retrieve its mapped wiki evidence, write LaTeX with verified citation keys/shared notation, and apply the writing polish. Honor `--sections`; do not rewrite unselected sections.

`--review` enables additional per-section `/llm-review` passes with standard difficulty and writing focus. Record actual findings/provenance and apply supported targeted fixes. The full-paper/scope review in Step 5 remains required regardless of this flag.

### Step 4: Build Bibliography

Following `shared-references/citation-verification.md`:

1. Collect all `\cite{key}` citations used across sections
2. For each citation, retrieve BibTeX from the PAPER_PLAN's citation plan:
   - Verified: write directly to `references.bib`
   - [UNCONFIRMED]: write to the bottom of `references.bib` with a `% [UNCONFIRMED]` comment
3. Exclude unused entries (do not use `\nocite{*}`)
4. Validate BibTeX format correctness (each entry has title, author, year)
5. Output bibliography statistics:
   ```
   references.bib: {N} entries, {M} verified, {K} [UNCONFIRMED]
   ```

### Step 5: Full-Paper Agent Review

After all planned sections are complete, perform a full-paper `/llm-review --difficulty hard --focus writing` in the current agent. This final review always runs; `--review` controls only the additional per-section passes. Follow `shared-references/review-protocol.md`.

Review the full LaTeX and PAPER_PLAN evidence map for:

1. A coherent narrative from Introduction to Conclusion.
2. Adequate evidence for each target claim, without overstating results.
3. Consistent notation across sections.
4. Figures and tables that are referenced and discussed.
5. Redundancy or gaps between sections.
6. Overall readiness (1–10), with specific unresolved issues.

Record the review mode and make supported final adjustments. Label review of the current agent's own draft `self-review`. For `--sections`, review the selected sections with any existing manuscript context; identify unavailable sections and limit the readiness assessment to the reviewed scope.

### Step 6: Finalize Output

1. Confirm all files are written to the selected external `PAPER_DIR`; report the actual absolute paths and source filename
2. Verify basic integrity:
   - all files referenced by `\input{sections/X}` exist
   - all files referenced by `\includegraphics{figures/X}` exist
   - all `\cite{key}` keys have a corresponding entry in references.bib
   - all `\ref{label}` have a corresponding `\label{label}`
3. Append log:
   ```shell
   uv run python -X utf8 tools/research_wiki.py log '@configured' "paper-draft | drafted {venue} paper '{title}' | {N} sections, {M} figures, {K} citations ({V} verified)"
   ```
4. Return the actual files, drafted scope, checks/review state, citation gaps, and next steps using [references/report-format.md](references/report-format.md). Draft delivery does not imply compilation or submission readiness. Respect draft-only/no-compilation requests; compilation is a separate action.

## Source grounding

This skill generates durable content, so it follows the shared **Source Grounding Discipline** — see `skills/shared-references/source-grounding.md`.

- Each section follows the plan's evidence map: wiki/prepared sources and identified proof, calculation, or observation records. Numbers, derivations, tables, and comparisons must trace to those actual sources; missing evidence stays a gap.
- Unverified citations carry the `[UNCONFIRMED]` marker until checked; never silently drop it.
- BibTeX + `[UNCONFIRMED]` per `citation-verification.md`; run a manual grounding self-check on every drafted section.

## Constraints

- **Each section follows the evidence map**: technical claims map to wiki claims/context and retrievable source evidence, including identified supplemental records; do not invent missing results or proofs
- **BibTeX follows citation-verification.md**: fetch from DBLP/CrossRef/`tools/fetch_literature.py` CrossRef wrapper; do not generate from LLM memory
- **De-AI polish is mandatory**: each section must receive a polish pass after writing; cannot be skipped
- **Figures follow academic-writing.md**: colorblind-safe, font size >= 8pt, vector format preferred
- **Submission identity**: follow confirmed venue anonymity/author requirements; an unspecified venue does not imply anonymous submission. Use placeholders for unknown authors in a new draft and preserve supplied metadata in existing drafts unless an authorized change requires otherwise
- **\nocite{*} is forbidden**: only cite entries actually used
- **Notation consistency**: all sections use unified symbols from math_commands.tex
- **External, independent manuscript storage**: use configured `paper_root`; edit the selected draft in place for routine revisions; create a sibling draft for major restructuring or independent evaluation. Keep backups in that draft's `history/`. Never generate manuscript content in the code repository
- **Wikilink → \cite conversion**: [[slug]] references in PAPER_PLAN are converted to \cite{key} in LaTeX
- **Tables use booktabs**: no vertical lines or full grid

## Error Handling

- **paper_root missing or invalid**: report the configuration error and the required external setting; do not generate content in the repository
- **PAPER_PLAN not found**: error; suggest running /paper-plan first
- **PAPER_PLAN format incomplete**: list missing sections; suggest re-running /paper-plan
- **Wiki page not found** (claim/experiment/paper referenced in plan does not exist): warn and skip that reference; annotate as missing
- **Figure generation failed** (matplotlib error): output placeholder `% TODO: generate figure {name}`; continue with other sections
- **All BibTeX fetches failed**: use [UNCONFIRMED] placeholders; report the count requiring manual handling in the terminal
- **Review evidence incomplete**: report the affected sections and missing evidence; keep the final review marked incomplete rather than silently skipping it
- **Venue template not found**: use generic article class; note in main.tex
- **Section too long** (exceeds plan page budget): warn; suggest moving to appendix or compressing
