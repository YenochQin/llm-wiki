# Omega Spillover

This directory holds optional OmegaWiki-era helpers that are useful to keep but
are not part of the core wiki-building path.

- `tools/remote.py`: remote GPU helper retained for compatibility.
- `config/server.yaml.example`: config template used by the remote helper.
- `mcp-servers/llm-review/`: optional Review LLM MCP server.

The main runtime stays in `wiki/`, `raw/`, `tools/`, and `skills/`.
